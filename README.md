# Frosz — Gelato Fit

Demo conceptual interactiva para Frosz con tipografía protagonista, bloques de color, producto flotante y transiciones entre sabores.

**Sitio publicado:** [frosz.com.ar](https://frosz.com.ar/)

## Experiencia

Incluye portada animada, historia de marca, selector de nueve sabores, puntos de venta filtrables, imágenes reales de producto, contacto, tarjeta social y soporte para movimiento reducido.

## Tecnología

Sitio estático desarrollado con HTML, CSS y JavaScript, sin dependencias de ejecución.

## Estructura

- `index.html`: portada.
- `contacto.html` y `contacto.js`: contacto.
- `script.js`: interacciones.
- `stores-data.js`: puntos de venta.
- `styles.css`: sistema visual.
- `public/`: recursos de marca.
- `CNAME`: dominio personalizado.

## Desarrollo y publicación

Puede abrirse directamente, aunque se recomienda un servidor HTTP local para probar rutas. La rama `main` se publica como sitio estático; `.nojekyll` evita el procesamiento de Jekyll.

Después de editar puntos de venta o recursos se deben comprobar filtros, versión móvil, enlaces y rutas relativas.

## Créditos

Contenido y fotografías basados en [frosz.com.ar](https://frosz.com.ar/). Demo diseñada y desarrollada por [Estudio Ideamos](https://ideamos.com.ar/).
